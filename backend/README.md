# Backend - DigiInvite

Supabase-based backend for DigiInvite.

## Directory Structure

- **database** - Database migrations, schemas, and seed data
- **edge-functions** - Supabase Edge Functions (serverless functions)
- **storage** - Storage bucket configurations and policies
- **api** - API endpoints and business logic

## Getting Started

Configure your Supabase project and deploy Edge Functions using the Supabase CLI.
