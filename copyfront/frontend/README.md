# Frontend - DigiInvite

React.js-based frontend application for DigiInvite.

## Directory Structure

- **src/assets** - Images, icons, fonts, and other static assets
- **src/components** - Reusable React components
- **src/pages** - Page components for routing
- **src/layouts** - Layout components (header, footer, sidebar, etc.)
- **src/routes** - Route configuration and navigation logic
- **src/services** - API calls and external service integrations
- **src/hooks** - Custom React hooks
- **src/context** - React context for state management
- **src/utils** - Utility functions and helpers
- **src/styles** - Global styles and CSS modules
- **src/supabase** - Supabase client configuration and utilities
- **src/fabric** - Custom design system components or utilities

## Getting Started

Install dependencies with `npm install` and run `npm start` to begin development.
